# AI Study Assistant 🤖

An AI-powered chatbot that helps students understand concepts.

## Features
- Chat-based interface
- Conversation memory
- Dark UI
- Knowledge-based responses
- Free AI model integration

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MongoDB Atlas
- AI: HuggingFace Transformers

## How to Run

### Backend
cd server
npm install
npm run dev

### Frontend
Open frontend/index.html
